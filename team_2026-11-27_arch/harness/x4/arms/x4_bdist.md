# x4_bdist: crack boundary loss (builder loss)

## What it changes
House CE + Dice plus alpha * L_B, L_B = sum(p_crack * phi * valid) / sum(valid) (Kervadec et al., Boundary loss for highly unbalanced segmentation, MedIA 2021, doi:10.1016/j.media.2020.101851, Eq. 5 and 6; arXiv:1812.07032).
- phi (level-set map of the crack): built per sample in the data workers from the augmented train mask (src/data/aux_targets.crack_sdf, through the x2 AuxTargetDataset path: no RNG, the batch stream is unchanged). Convention of their code (one_hot2dist): outside = distance to the nearest crack px, inside = -(distance to the nearest non-crack px - 1); then 0 within 2 px of the crack (offsets that relF1@2 accepts cost nothing) and clipped to [-20, 20] px. A cell without crack gets a zero map (their Sec. 3.5). Ignore px (255) excluded in the loss.
- Schedule (their Sec. 3.4 / 3.5, "increase"): alpha = 0.01 + 0.01 per epoch of 54 steps (ceil of 421 to 431 train cells / 8), capped at 1.0; reaches 1.0 at step 5,346, so the whole SWAD window (10k to 20k) runs at alpha 1 (equal weights, as their "increase" ends).
- S: "rebalance" (their default) not used: with 1 to 2 px cracks phi is about 0 inside the crack, so L_B only pushes crack probability down beyond the tube; a late regional weight of 0.01 would cost recall. Available as loss.bdist.schedule=rebalance (alpha_max < 1 enforced).
- Precomputed inputs: none on disk (the map is a deterministic function of the augmented train mask; fold-safe by construction: only the run's own train cells).
- Keys: loss.bdist.{enabled=true, cls=14, tube=2.0, clip=20.0, schedule=increase, alpha0=0.01, alpha_step=0.01, alpha_max=1.0, steps_per_epoch=54}. Log: 'thin loss_bdist=... bdist_alpha=...' lines in train.log (the step line is unchanged).
- Code: src/losses/x4_losses.py (BoundaryDistLoss), src/data/aux_targets.py (crack_sdf), src/losses/loss_factory.py, src/trainers/trainer.py (set_step hook: losses without set_step, e.g. the house loss, are not touched).
- Run time (S): as COMBO (CPU EDT per sample in the workers).
