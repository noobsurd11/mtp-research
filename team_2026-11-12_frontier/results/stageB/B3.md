## 1. Reading rules (written 15 Nov about 13:08 IST: after one code-check run of the U5 tool on gaint PF alone (200 draws; PF's own level and its A/A, no arm contrast), before any R0 number and any U5 arm contrast)

### 1a. U5 read (CSIR multi stratum of CV5, out-of-fold, existing dumps)
- Printed per arm: crack relF1@2 at OP-A (argmax) with relP@2 and relR@2, relF1@1, strict crack IoU, width ratio, matched-precision relR@2 (max relR@2 at relP@2 >= 0.90 on the crack-bias curve; descriptive), crack-free false alarms (px per cell, share >= 50 px), inactive IoU (descriptive only), and the effective n of the read.
- M_U5 = max(0.01, 2 x SE of the A/A contrast PF seeds {5,6} v {7,8} on the same 32 cells), per machine (T7 0.3 rule, applied to the subset itself).
- A row - PF contrast "differs" only if |delta| >= M_U5 with the 95% interval excluding 0 at OP-A AND the frontier contrast (relR@2 at PF's argmax relP@2, width ratio beside it) has the same sign with its interval excluding 0. Any interval holding 0 is "no information". No arm pre-declared U5, so every U5 contrast here is descriptive (multiplicity: 7 rows, 2 machines).
- Machines are never mixed in one read (gaint: PF seeds 5 to 8; cv02: PF 5 to 9, HOUSE, PFV1, the five tranche 1 rows).

### 1b. R0 (T7 0.5 rule, fixed 13 Nov, with the Y2 fixes)
1. Every contrast is read at the frontier (relR@2 of arm B's bias curve at arm A's argmax relP@2 minus A's own curve there) with the width ratio B / A at that point and a two-stage bootstrap interval (module groups, then one seed per arm; 2,000 draws). An interval that includes 0 is "no information", never a pass. Effective n is printed for every read.
2. A read is used as a crack primary only if it gives a positive frontier contrast (interval above 0) for every confirmed crack mover and does not rank HC above them on a read HC was not trained on (U3, U4). U2' (SHV1) is exempt from the HC clause.
3. After SKR2C (final 14 Nov: R and D FAIL, not replicated at recipe level) there is no confirmed crack mover (Y2 (b)). Under rule 2 no read can therefore be qualified as a crack primary by R0; R0 can only falsify. SKR2 - PF is printed as descriptive.
4. HC null: on U3 (F51; HC never trained on it) an HC - PF frontier interval above 0 with width ratio inside 0.85 to 1.15 contradicts the E1 HC null (+0.0135 n.d.) and the read is kept as a guard only. On U4 (H36 crack-free) the HC - PF false-alarm contrast is descriptive (BRIEF 5: HC gave fewer half-cut false alarms, so a drop there agrees with E1 either way).
5. Inactive anchor: PF - g inactive IoU at b = 0 (E1: +0.189 BETTER). Interval above 0 = the read agrees with E1; below 0 = the read disagrees and is kept as a guard only for inactive; holding 0 = no information. Only the same-machine pair (PF0 - G0, calib records of SUP100-PF / SUP100-g seeds 0 to 4) decides; the cv02 FINAL-member proxy for g is descriptive.
