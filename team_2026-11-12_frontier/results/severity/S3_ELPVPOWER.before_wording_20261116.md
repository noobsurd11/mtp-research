### 1.1 Units and the analysis subset (CPU run)
- **Measurement** = one row of `data.csv` (one EL image). **Electrical measurement** = one distinct (module_instance, pressure, peak_power); the high / low image pairs share one.
- **Analysis subset S137 (pre-declared primary unit):** for each of the 137 module instances, its lowest-index row with `excitation_class = high`. 137 rows, 8,388 cells (T1 64 x 60, T2 14 x 72, T3 59 x 60). Chosen by file index and excitation only, never by power.
- **Why this subset and not a seeded random 15% (S):** S137 gives one row per module instance, so all 137 independent units enter once and the bootstrap groups are the rows; a random 15% of rows (108) would draw about half its rows from the 10 load-series instances (448 of 719 rows) and so hold far fewer independent instances. Budget: 8,388 cells x 5 models = 41,940 forwards; at 1.75 s per forward per worker and 8 workers about 2.5 h (inside 8 h). The full set (43,476 cells x 5 = 217,380 forwards, about 13 h at that rate) exceeds the CPU budget: it goes to a prepared GPU job list (1.9).
- If a cell of an S137 row fails the automatic geometry check (1.4), the row is dropped from every statistic and counted; more than 7 dropped rows (5%) is reported as a deviation for the lead.

### 1.2 Relative power loss (spec 8, applied)
- L = 1 - Pmpp / Pref. Pref = Pmpp of the same instance's first electrical measurement (lowest file index; the set has no time stamps, S) when the row belongs to a later electrical measurement of that instance; otherwise Pref = nominal power.
- On S137 every row belongs to its instance's first electrical measurement (asserted in code; any exception is reported), so Pref = nominal for all 137 rows. S: the T1 instances measured once or twice may already be degraded or below nameplate for reasons other than visible damage; this is part of what the test measures.

### 1.3 Model and per-cell quantities
- Models: PF v1.1 (house_r34_unetpp_pf_v11), seed 5, folds 0 to 4 (`el_bench/experiments/w1g_pf_v11_f<k>_s5/checkpoints/latest.pth`, step 20,000), loaded as in `scripts/sev_a3_infer.py` (S4), fp32, CPU; ensemble = mean of the 5 softmax maps; class map = argmax. No fold model saw any ELPVPower image (gate (c) tests the training cells).
- Cell image (BMRK geometry, as spec 8 says "as BMRK cells are"): the cell box from the cutting (1.4) is resized to 256 x 256 px (area interpolation if smaller, linear if larger) and centred in a 512 x 512 canvas of 255 (white padding), as the 50 BMRK pool cells are (E: content box rows and columns 128 to 383, padding 255). Intensity: per module, the linear map that sends the module's p1 and p99 (pixels inside the detected grid) to 20 and 171 (the medians over the 50 BMRK pool cells of their central-region p1 and p99, E 23:31), clipped to [0, 255]. One map per module, not per cell, so a dark cell stays dark against its neighbours (S).
- Per cell, on the central 256 x 256 region, by `bench/sev_a3.cell_record` (the S4 code): a = derived inactive area fraction (PROTOCOL 4.4 derived region: inactive plus enclosed crack px; % of non-padding px of the region); crack length = skeleton px of predicted crack (512 px geometry, cell = 256 px).
- Per row: **A = sum over the row's cells of a / 100** (cell equivalents; the spec's "module sum"); **C = sum of crack skeleton px**. Printed beside, decide nothing: A_mean = A / number of cells, worst cell a_max, number of cells with a >= 1% (Gabor "critical" threshold).

### 1.4 Gates (spec 8: all three must pass before the analysis is read)
- **(a) User OK to download:** given 15 Nov (log 21:46 lines; the lead's task). Pass.
- **(b) 20-module pilot of automatic cell cutting.** Pilot = 20 S137 rows drawn by `numpy.random.default_rng(20261115)`: 7 of the T1 rows, 6 of the T2 rows, 7 of the T3 rows (each type's rows in index order, `rng.choice(n, k, replace=False)`, T1 then T2 then T3), never looking at power. ### 1.5 Primary statistic
- **rho_A = Spearman rho (average ranks) between A and L over the S137 rows that pass 1.1, all types pooled.** Interval: bootstrap over module instances, 2,000 draws, `numpy.random.default_rng(20261115)`, percentile 2.5 / 97.5 (on S137 each instance has one row, so this resamples rows). Draws with a constant input are dropped and counted.
- **Comparison:** rho_C = Spearman rho between C and L, on the same draws. D = rho_A - rho_C per draw; SE(D) = standard deviation of D over the draws; D's point value from the full sample.

### 1.6 Decision rule (spec 8, word for word in substance)
- **rho_A >= 0.6 and D > SE(D):** v0.2 adds an external validity row "predicted inactive fraction vs measured power", and T5's inactive bands become a severity output with this evidence.
- **Otherwise:** severity stays parked and the row reports the null.
- The reading is made on S137 (CPU, this item). The full-set run (1.9), if the lead arms it, is read with the same rule (bootstrap grouped by instance) and printed beside; it does not replace the S137 reading, and if the two disagree the lead decides.

- rho with L of A_mean, a_max and the count of cells with a >= 1%.
- **The paper's own baselines (R):** SVR 9.0 W, ResNet18 7.3 W, inactive-area threshold 8.5 Wp MAE, all on 719 rows with the paper's 5 folds. **Ours beside them (E, not comparable: 137 rows, one per instance):** OLS of Pmpp / nominal on A_mean (with intercept), fitted on the S137 rows of the paper's training fold k (`fold_k_train` = True) and applied to its held-out rows, k = 0 to 4; MAE in W = mean of |nominal x predicted ratio - Pmpp| over all held-out rows; the same with crack length per cell (C / number of cells) and with a constant (training-fold mean ratio).

### 1.8 What this cannot say (S)
Module-level power hides which cells cause it; on-site Pmpp carries >= 5% uncertainty (R P263); a domain gap (other camera, 150 px cells upsampled 1.7x into BMRK geometry, global grey rescaling) can make our inactive predictions poor, and then the test measures transfer, not severity. A pass supports "predicted inactive area ranks modules by measured power loss on ELPVPower"; it says nothing about a power band per cell on our own cells.

### 3.3 What this means (S)
- Gates (a), (b) (as ruled, with the pilot-2 and 8-row deviations noted), (c) passed; the rule's verdict is **NULL**, so no external validity row and T5's inactive bands are not promoted to a severity output on this evidence.

The only within-type range where they can be told apart (T3) favours inactive area, but that is a beside-figure.
