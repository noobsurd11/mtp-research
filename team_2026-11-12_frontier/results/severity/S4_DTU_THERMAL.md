### 1.2 Sample and label (v1 section 2, as decided at the 4 Nov discovery)

- **Primary label (v1 fallback, module type not recoverable): FF loss = 1 - FF / median FF over all non-soiling modules.** Per module from the I-V csv: Pmax = max(V x I) over the measured points; Isc = I at V = 0 by linear interpolation between the two points that bracket V = 0 (the point nearest V = 0 if none bracket); Voc = V at I = 0 likewise; FF = Pmax / (Voc x Isc). ### 1.3 3b-R1: does an EL darkness proxy track the measured loss?
- **EL proxy (pick 1 R2 + Amendment 6 rule 2, frozen definitions):** NEF read by cellreg's `read_nef_preview` (largest embedded JPEG, 8-bit, tone-mapped; approximate). Module quad by cellreg `find_quad` (Otsu outline; EL has a dark background). Rectified by the quad homography (no grid refinement; R2 needs only the outline) to the canonical grid of the module's lit layout at S = 128 px per cell. Module interior = the rectified module minus a 3% inset on every side. Module median = median over cells of each cell's inner-90% median (cellreg `el_features` convention). Dark px = interior px < 0.5 x module median, after a binary opening with a disk of radius round(0.02 x 128) = 3 px. **EL dark fraction** = dark px / interior px.
- Diode-class modules (Amendment 6 rule 2): the lit layout (lit rows x cols) and the full layout (60 or 144 cells) are read by eye from a contact sheet of the EL previews at discovery and logged before any value; dark fraction = (dark px inside the lit outline + missing cells x median cell area) / (all cells x median cell area), computed as (dark_frac_lit x n_lit + n_missing) / n_all.
- Layout per module (60-cell 6 x 10, half-cut 6 x 24, or lit part) is likewise read by eye at discovery and logged before any value.
- **Statistic:** Spearman rho (average ranks) of EL dark fraction with FF loss, all non-soiling and non-diode, with a module bootstrap 95% percentile interval (2,000 draws, `numpy.random.default_rng(20261104)`; draws where a statistic is undefined because an input is constant are dropped and counted).
- **Verdict (v1, unchanged):** label-valid if rho >= 0.5 with interval lower bound > 0; label-invalid if rho < 0.3; in between "weak"; fewer than 15 modules: not computed. The claim "the EL dark proxy is a physics-anchored inactive label on A3" needs label-valid on the **non-diode** set. A non-diode rho < 0.3 is read as "not separable from a too-narrow label range", not as "EL proxy invalid" (v1 reading rule, kept).
- Within module type: not computable (no type); not reported.

### 1.4 3b-R2: does drone thermal track the loss, and does it add to EL? (this is the thermal rule the amendment fixes)
- **IR score (pick 1 R1 as amended by Amendment 6 rule 1, adopted here for 3b-R2):** per frame, S_IR = p99 - median of the temperature array inside a 3% inset on every side (the whole array is the module; Otsu is not used). Per module, S_IR = median over the frames at 600, 800 and abv800 W/m2, all altitudes. Frames read as float32 little-endian, shape 605 x 363; a file whose size is not 605 x 363 x 4 bytes is dropped and counted. Irradiance and altitude are parsed from the file name (`..._<alt>m_<irr>.raw`).
- **Readouts (v1, unchanged):** (a) Spearman rho(S_IR, FF loss) with the module bootstrap interval; (b) leave-one-module-out OLS (with intercept) of FF loss on [EL dark fraction] and on [EL dark fraction, S_IR]; held-out R2 of each and ΔR2 = R2(both) - R2(EL); bootstrap interval of ΔR2 (same 2,000 draws; inside a draw, leave-one-out leaves out every copy of the held-out module); (c) FF loss is already the primary label, so v1's "(c) the same on FF loss" is the primary itself. All on all non-soiling and on non-diode.
- **Secondary, fixed now, decides nothing:** partial Spearman rho(S_IR, FF loss | EL dark fraction) = the Pearson partial correlation of the three rank vectors, with the same bootstrap interval. It is printed because linear OLS on skewed values with a few large diode modules can be driven by one point (S).
- **Verdict (v1, unchanged):** drone IR is a power-loss proxy if rho(S_IR, FF loss) >= 0.5 with interval lower bound > 0; not a proxy if rho < 0.3; IR adds to EL if ΔR2 >= 0.10 with interval lower bound > 0; "no added value" if ΔR2 < 0.05; otherwise "in between". The claim reading uses the non-diode set (v1 caveat: the diode class can drive rho by itself).
- **3b-R3 (cell-level thermal by cause): not run in this item.** Reasons: (1) v1 section 5 needs pick 1's R3b registered cells with a visual QA co-signed blind by an independent check agent; R3b was never run and this item has no co-signer; (2) the lead's task for this item forbids any cell-level thermal claim, because the 4 Nov study found the dark thermal signal row-level (handbook 22 section 10 item 2). 3b-R3 stays open; if it is ever run, Amendment 6 rule 3 (full-array IR quad, 90 degree turn, four orientations with a best-of-4 permutation null) is its registration rule, and pick3b's interconnect-stratum verdict lines apply unchanged.
- 3b-R4 (two-current EL): not run (one EL per module; v1 rule, decided at discovery).

### 1.5 S4-Q3 (this track's question): does segmentation-based severity track the loss better than the plain EL darkness proxy?
- **Cell cutting.** EL preview (as 1.3); frozen cellreg `register` (Otsu quad, detected grid, 3 iterations, S = 128) with the module's layout from discovery (lit layout for diode modules) gives the refined homography canonical -> image. Each cell is cut by my own code with that homography into a BenchmarkEL-geometry crop: the crop is 512 x 512 px with the cell centred, the cell's long pitch mapped to 256 px (full cell 256 x 256; half-cell 256 along its long side, 128 along its short side), and half a full pitch (128 px) of the neighbours or the image background on every side. E (measured 15 Nov on 176 train cells of fold 0, ARTS / CFVS / CSIR, before this rule): BenchmarkEL cell gaps sit at about 128 and 384 px, so the central cell is about 256 px with half a cell of context. Intensity: per module, a linear map of the [1st, 99.5th] percentile of the module-interior px (lit outline, 3% inset) to [0, 255], clipped, 8-bit. Bilinear sampling.
- **Cutting QA (pick 1 v2 criteria fae36d53 items 1 to 4, applied to EL only, by me, not co-signed):** per module, an overlay of the refined grid on the EL preview and a contact sheet of every crop. A module fails if any inner grid line sits more than about 10% of a cell off its gap, the grid overruns or stops short of the module edge by more than about 10% of a cell, a crop's central cell visibly holds parts of two cells, or the count / orientation is wrong; it also fails if cellreg's residual RMS > 5% of a cell side. Calls are logged before any prediction is summarised. A failed module is excluded from S4-Q3 only (R1 / R2 use the quad and are unaffected) and counted. S4-Q3 is computed only if at least 15 usable modules remain in the set; otherwise "not computed".
- **Models.** The PF baseline `house_r34_unetpp_pf_v11`, seed 5, folds 0 to 4 (`el_bench/experiments/w1g_pf_v11_f<k>_s5/checkpoints/latest.pth`, step 20,000, key `model`), the predict path of `bench_infer.py` (eval transform, fp32, CPU). No fold saw any A3 image. Ensemble = mean of the 5 softmax maps; class map = argmax of the mean. Seed 5 only: 5 x 1.8 s per crop on one CPU thread (E, timed 15 Nov) keeps the run under 1 h with 8 workers; T12 section 8 also used the 5 fold models.
- **Per cell (central-cell region of the crop only):** derived inactive region R = I or (C and (closing(I, 5 x 5) or fill_holes(I))) with I = class 11, C = class 14 (S1 rule 1.2, the same function, `bench/post_eval.py`); inactive area fraction a = |R in region| / |region and map != padding|; isolation risk s = S1's c_phys rule (`bench/post_eval.py`, which reproduced c_phys.json 532 / 532), computed on the whole 512 crop and restricted to the central-cell region (isolated px in region / region px). Crack skeleton px in the region (descriptive, "not a power proxy, P617").
- **Per module:** **seg inactive fraction** A_seg = mean over the module's cells of a (in %); for diode modules the unlit (missing) cells count as a = 100% (the same rule as the EL proxy, Amendment 6 rule 2). Secondary: isolation risk module mean S_iso (missing cells count as 1); worst cell a (descriptive); crack skeleton px per cell (descriptive).
- **Primary statistic, non-diode set (primary, because in diode modules both measures share the imputed missing-cell area):** Δrho = rho(A_seg, FF loss) - rho(EL dark fraction, FF loss), with a paired module bootstrap interval (the same 2,000 draws for both). Also printed: each rho with its interval, on non-diode and all non-soiling; the same for S_iso (secondary).
- **Verdict (fixed now):** "segmentation severity tracks the loss better" if Δrho >= 0.10 with interval lower bound > 0; "EL proxy better" if Δrho <= -0.10 with interval upper bound < 0; otherwise "no difference shown". Separately, A_seg itself: "tracks" if rho >= 0.5 with lower bound > 0; "does not track" if rho < 0.3; else "weak" (the 3b-R1 bars). A non-diode rho < 0.3 for both measures is read as "not separable from a too-narrow label range" (as 3b-R1).
- **What each outcome means:** better = the predicted inactive area, not just dark pixels, is the better severity input on A3 (still one public set of 24 lab-damaged modules, module-level, FF loss only); no difference = the segmentation adds nothing over a threshold on EL at module level on this n (a wide interval is likely, S); EL better = our models' inactive predictions on these unseen modules are worse than a darkness threshold, which measures transfer as much as severity (T12 section 8 risk).

### 1.7 Intervals and n needed
- Every rho is printed with its interval and n. Nulls are reported as nulls.
- n needed (fixed formula): for a true Spearman rho, the n for 80% power that the 95% interval excludes 0, n = ((1.96 + 0.84) / atanh(rho))^2 x 1.06 + 3 (Fisher z with the Fieller-Hartley-Pearson factor), printed for rho = 0.3, 0.5 and the observed values. For Δrho no closed form is used; the observed interval width is printed and the n to halve it is stated as about 4 x the current n (S: interval width ~ 1 / sqrt(n)).

## 4. Reading (S)
- **3b-R1.** On the non-diode set the EL dark proxy passes the frozen bar (rho 0.64, lower bound 0.24), so by v1's rule it is a physics-anchored inactive-like label on A3. The rank order is carried mostly by the interconnect modules (cut ribbons give dark bands and the largest FF loss) and, at the low end, by the 2 glass modules of another type; without glass it is unchanged (0.63, post hoc). The all-module null is a label effect, not a proxy failure: diode modules have the most EL darkness (missing substrings) and large Pmax loss, but FF does not see it.
- **3b-R2.** Drone thermal (S_IR) is not a power-loss proxy for the inactive-like defects here (rho 0.19 non-diode), and no added value over EL is shown (ΔR2 +0.10, interval -0.18 to +0.40; partial rho -0.12). Its large values are the diode modules (S_IR 16 to 30 deg C) and most soiling modules (up to 38; two near 1), against 0.75 to 1.7 for cracks, interconnects, PID and glass, which matches the DTU paper (diodes and soiling hot; cracks hard to see) (R). This is module level only; nothing here says anything about cell-level thermal.
- **S4-Q3.** By the frozen rule, segmentation severity tracks the loss better than the EL dark proxy on the 16 usable non-diode modules (Δrho +0.46, lower bound +0.009; rho(A_seg) 0.90). Read it narrowly: (1) the lower bound is barely above 0, and on all 18 usable modules the same comparison is "no difference shown"; (2) cutting failed on the four highest-loss interconnect modules, so the 16 span only -0.7% to +2.9% FF loss and the comparison is mostly crack modules vs PID and mild interconnect modules; (3) what drives it (post hoc, not a test): A_seg orders the crack modules by loss (rho 0.79 within cracks, n = 8) and puts PID modules low, while the dark-pixel proxy counts PID's dark cell edges as dark; the post hoc Pmax-loss view agrees (0.76 vs 0.29). That is the direction the literature expects (inactive area, not darkness or crack length, drives loss; P263, P617 via the T12 spec) (R). It is the first time our predicted inactive area has been checked against measured electrical data, on one public set of lab-damaged modules, at module level; it is not a validated power estimate, and FF / Pmax differences of 1 to 2% are near what one would expect from I-V repeatability (S, not measured here).
- **What this changes (S):** on the 16 modules that could be cut (a subset that excludes the four highest-loss interconnect modules, where the EL darkness proxy is strongest), predicted inactive area ranked FF loss better than EL darkness; the interval's lower bound is at 0 and depends on the bootstrap seed (<= 0 on 3 of 8 seeds, reviewer's check). This is a borderline result on a selected subset, not evidence that segmentation beats EL darkness in general [wording fixed 16 Nov, review F4.1]. It does not contradict S1's choice of inactive area as the severity quantity; the isolation risk adds nothing visible beyond A_seg here (it fires only in crack modules) and was already dropped by S1's D1. The weak point is cell cutting, not the models: the informative modules (heavy interconnect damage, half-cut) are the ones the frozen uniform-grid tool could not cut.
- **Transfer of the predictions to A3 (S; added 16 Nov from the review, F4.2).** The frozen rule had a cutting QA (geometry) but no prediction-quality gate, and no prediction sheet existed before the statistics. The reviewer made one after the fact (`rv_s4_pred_sheet.jpg`: the worst cell and cell r2_c5 of each of the 18 cut modules) and saw:
  - On crack modules, cracks are drawn well and isolated dark fragments are marked inactive: good transfer.
  - On edge and bottom-row cells, inactive leaks in from the black background outside the module (cracks_M7 r5_c0 0.3%, PID_M2 r5_c6 3.9%, PID_M3 r5_c4 3.7%, diode_M4 r3_c0 0.4%). This adds a small false A_seg, mostly to the low-loss PID modules.
  - PID-darkened (shunted) cell regions are partly labelled inactive, which is not the meaning of "isolated".
  - These do not change the verdict: they inflate A_seg on low-loss modules, which works against the observed rho.
