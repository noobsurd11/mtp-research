# Datasets with EL + thermal (and EL + PL / UVF / RGB) for PV: table

Owner: datascout. Status: v3 (2026-11-04), check pass-1 fixes applied (ids D-# refer to check/factcheck.md §2). Search log and near misses: `notes.md`.

Tags: **E** = measured in our files (path); **R** = from a source (URL / DOI / Research MCP id); **S** = my reasoning. "unconfirmed" = could not verify from metadata.
All facts below come from dataset pages, API metadata, READMEs and paper abstracts / sections read on 4 Nov 2026. No dataset files or archives were downloaded (one 1 KB README was read, see notes.md).

Pairing levels: **module** = same physical module imaged in both modalities, separate cameras, no registration given; **cell** = same cell(s), crops or IDs that map one to one; **pixel** = registered images (same camera / same geometry).

## Ranking: 5 most useful for us (crack / inactive EL segmentation, unseen modules)

1. **A1, OSF csr6t (UCF DPV, 156 Shell M55 modules, EL + IR + UVF + I-V, CC BY 4.0).** Largest open set with EL and thermal on the same modules, plus per-cell dark I-V from EL. About 156 x 36 = 5,600 EL cells (S). IR for 157 modules, one bias-matched capture each (3.39 A, 180 s, raw txt + jpg), with an EL frame at the same current [R: file names]; only 0.26 GB. Cell-level alignment by per-module homography is feasible (S). Gives cross-modal pairs for distillation and a physics weak label for inactive / high-Rs cells. Caveat: old Al-BSF full cells, no half-cut cells; losses are mainly resistive from rear-contact Ag/solder corrosion (R: Colvin 2023), so cracks are probably a minor mode (S).
2. **A3, DTU drone IRT + EL + I-V (43 artificially degraded modules, CC BY 4.0).** The only open set where cracks and interconnect disconnections were induced on purpose and imaged in both EL and field IR, with module-level defect labels. Tests directly whether IR sees our classes; the paper already says cracks are hard to see in IR while disconnections are visible (R). Best set for the "drone IR screens, EL details" pipeline idea (S).
3. **A2, OSF ar76v (UCF DPV, 42 SolarWorld modules; 15 with forward-bias IR at 5.29 A, 16 captures).** Small but the cleanest bias-matched EL + IR pairs (IR under current injection, EL at several biases), so hot = disconnected / high-current-density areas can be compared to EL-dark areas cell by cell (S).
4. **C1, Polenghi et al. EL + NIR + VIS HDR, 84 progressive damage stages with power (CC BY 4.0).** Pixel-aligned, crack growth to inactive area with measured power at each stage. No thermal, but a clean severity / inactive-growth series for testing whether our inactive predictions track power loss (S).
5. **D-group thermal pools for a thermal teacher or IR pretraining: D3 + D2 (UCF UVF 7,190 modules; IR-visual 1,898 pairs; CC BY 4.0) and D1 InfraredSolarModules (20,000 labelled crops, MIT; its 941 "Cracking" crops are "cracking on module surface", not cell cracks, R: README via check D-21).** Not EL-paired, but large and licensed; D2 / D3 share naming with A1 / A2 modules from the same FSEC group, so some modules may link to EL (S, unconfirmed).

Honourable mentions: B5 / B4 (NREL field PL, including 856 half-cut-cell images; DuraMAT hub unreachable on 4 Nov) for the half-cut problem; E4 (NREL DLIT + EL + PL on a half-cut module) if obtainable.

Bottom line (S): no public set gives pixel-registered EL + thermal at cell level with crack / inactive masks. Three open sets (A1, A2, A3; about 240 modules in all; about 215 have IR: A1 157, A2 15, A3 43 [R: file listings, check D-24]) give module-paired EL + IR from which cell-level pairs can be built by homography. That is enough for a feasibility study of cross-modal weak labels and for a demo pipeline, not for training a fusion model at scale. A small own capture (capture agent) would fill the gap on modern half-cut modules.
