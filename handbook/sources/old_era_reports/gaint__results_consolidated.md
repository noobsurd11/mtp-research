# Consolidated BenchmarkEL results: gaint + cv02 (current code)

Generated by `scripts/consolidate_results.py` from each run's `metrics.json` (test, final step) and
`eval_final_valtest_cpu.json` (val + test pooled, final step, CPU re-score). CSV: `reports/results_consolidated.csv`.

* Test: 50 images; val+test: 104 images. `defect_miou` is the mean IoU of crack and inactive. Final-step weights only (no checkpoint selection).
* All runs: bf16, current code (fixed augmentation), 20,000 steps, labelled batch 4 unless the arm name ends in `-b8` (`training.labeled_batch_size=8`;
  gaint, night of 2026-10-05); `-noCW` = plain CE, no class weights (`loss.supervised=ce`). The 10 % and 20 % arms use the seed-0 labelled subsets
  (9 / 23 / 47 / 95 images for 2 / 5 / 10 / 20 %), and `seed` is the training seed only. MT and SA-MT use labelled view strong. Pilot runs (coupled-augmentation code) are excluded.
* Config check: within each arm, configs differ only in seed / run name / split seed: **yes, for every arm**.
* **Seeds run on both machines:** SL-20 [0, 1, 2], SL-100 [0], SA-SL-20 [0], MT-20 [0, 1, 2], ALHVR-20 [1]. These pairs share the initialisation and the data / augmentation stream and differ only through non-deterministic GPU kernels
  (cuDNN-deterministic mode, not bitwise). They are therefore not fully independent replicates.
* `cv02.md` was not in `experiments/cv02_sync/` and is not used.
