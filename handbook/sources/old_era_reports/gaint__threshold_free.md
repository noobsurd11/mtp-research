* **What:** for crack and inactive, the PR curve of the softmax probability of that class over every pixel, with one threshold per
  probability bin (1000 equal bins on [0, 1]); AP = Σ_k (R_k − R_{k+1}) P_k (step-wise, as sklearn's `average_precision_score` on the
  binned probabilities). `defect mAP` = mean of the crack and inactive AP, the threshold-free analogue of `defect_miou`.
* **Weights:** final step (`latest.pth`): EMA teacher for MT, network A for ALHVR. One forward pass over val + test, eval transform
  (no augmentation), bf16 autocast on the GPU (the trainer's test path). IoU / P / R columns are the argmax of the same pass.
* **Runs:** every finished BenchmarkEL run on gaint with a final checkpoint (24 runs). cv02 has no checkpoints here, so **all numbers and tests below are gaint only**; the pooled
  gaint + cv02 `defect_miou` is in `results_consolidated.md`.
