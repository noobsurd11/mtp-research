# ALHVR port notes

Sources:

* **Paper**: Lei et al., *Adaptive Learning of High-Value Regions for Semi-Supervised Medical Image
  Segmentation*, ICCV 2025 (`docs/papers/ALHVR_Lei_ICCV2025.pdf`). Equation numbers below are the paper's.
* **Reference code**: `refs/ALHVR/train_ALHVR/code/`: `train_ALHVR_acdc.py` (training loop and all
  unlabelled losses), `networks/unet.py` (`UNet_fea_aux`, perturbations), `utils/Generate_Prototype.py`
  (prototypes, cosine), `utils/ramps.py` (λ ramp).

Notation: networks A and B (code `model1`, `model2`). Suffix 1 = unperturbed ("main") pass, suffix 2 =
perturbed ("aux") pass. `con = max softmax`. All unlabelled losses use the unlabelled part of the batch
only (code: `[labeled_bs:]`).

Where paper and code disagree, **the port follows the code**, and each disagreement that changes the
loss value gets a flag whose default reproduces the code (section 9).

---

## 1. Architecture and perturbation (Eqs. 1–2)

| | Paper | Reference code |
|---|---|---|
| Networks | Two networks f_A, f_B with the same structure, updated independently. | `model1`, `model2` = `UNet_fea_aux`, built one after the other from the same global RNG, so they get different initial weights. Two SGD optimizers. No EMA. |
| Perturbation | "Feature perturbations are generated by randomly adding noise or dropout." | `random.random() > 0.5` → `FeatureDropout` on **every** encoder level, else `FeatureNoise` on every level. One coin flip per forward call, shared by the whole batch and all levels; each network flips its own coin. |
| FeatureDropout | – | Channel-mean attention map; per image, threshold = max(attention) × U(0.7, 0.9) (one draw per level, shared by the batch); zero all channels where attention < threshold. |
| FeatureNoise | – | x ← x + x·n, n ~ U(−0.3, 0.3) with shape (C, H, W), drawn once per level and shared across the batch. |
| Decoder for the perturbed pass | Same decoder f^d on F_2. | `self.decoder(aux_feature)`: same weights, the same BN layers in train mode (BN running stats are updated by both passes). |
| Feature used for prototypes ("F^d") | "Features from the second-to-last layer of the decoder" (text under Eq. 15 and Eqs. 5–6). | `Decoder_fea` returns `x6`: the 1×1-conv projection inside `up2` of the **first** decoder stage's output, 64 channels at 1/8 resolution. This is not the penultimate layer. |
| Input | – | The same augmented batch goes to both networks (one view). |

## 2. Supervised loss (Eqs. 3–4)

| Paper | Code |
|---|---|
| L_s = L_ce(ŷ_a1, y) + L_dice(ŷ_a1, y), on the unperturbed output only. | Same: `F.cross_entropy` (unweighted) + `DiceLoss` on `outputs1[:labeled_bs]`. The perturbed output of the labelled images is computed but unused. |

## 3. Adaptive threshold γ (Eq. 11)

| Paper | Code (`generate_threshold`) |
|---|---|
| con = sorted pixel-wise mean of con_a2, con_b2 (**perturbed** passes); γ = mean of the lowest K values, K = β·(H·W·Z), β ∈ (0,1). β = 0.8 for ACDC. | `con = (max_value_aux1 + max_value_aux2)/2` over the whole unlabelled batch; `k = int(con.numel() * proportion)`; γ = mean of the k smallest (`topk(largest=False)`). `proportion = 0.8`. γ is pooled over the batch rather than per image. |

## 4. Regions (Eqs. 12–14, 17–18, 23)

All regions are defined on the **perturbed** confidences con_a2, con_b2.

| Region | Paper | Code |
|---|---|---|
| Ω1 reliable stable | con_a2 ≥ γ & con_b2 ≥ γ | Not computed (no loss). |
| Ω2 reliable unstable, A learns from B (Mask_a) | con_a2 < γ & con_b2 > γ (Eq. 17) | `(aux1 <= γ) & (aux2 > γ)` |
| Ω2, B learns from A (Mask_b) | con_a2 > γ & con_b2 < γ (Eq. 18) | `(aux2 <= γ) & (aux1 > γ)` |
| Ω3 unreliable stable | con_a2 < γ & con_b2 < γ (Eqs. 14, 23) | `(aux1 < γ) & (aux2 < γ)` |

The paper's sets leave the ties (con = γ) unassigned. The code's `<=` and `<` assign some of them to Ω2 and
leave others (e.g. aux1 = γ & aux2 < γ) in no region. **Port:** the code's Ω2a / Ω2b / Ω3 masks exactly, and
Ω1 = everything else, so the four masks partition the pixels. This only matters on exact float ties.

## 5. CG-CPCL: cross-prototype consistency on Ω2 (Eqs. 5–6, 15–20)

### 5.1 Prototypes (Eq. 15)

| Paper | Code (`compute_prototypes` / `getPrototype_2D`) |
|---|---|
| p^c_a1 = Σ F^d_a1·𝟙(ŷ^p_a1 = c) / Σ 𝟙(ŷ^p_a1 = c): a **pixel-pooled** class mean of the unperturbed features, pseudo-label = argmax of the unperturbed output. Features upsampled to label size. | Features bilinearly upsampled to full resolution. **Per image** masked mean (`sum / (count + 1e-5)`), then summed over the batch and divided by the batch size B. Images without class c contribute a zero vector. A class absent from the whole batch gets a **zero prototype**, which is still used (cos = 0 against it, and it is a CE class). Prototypes are **not detached**: gradient flows into the main features. |

Cosine similarity is scale-invariant, so dividing by B (rather than by the number of images that contain c)
does not change any loss. What does differ from the paper: the code weights images equally, while the paper
weights pixels equally. The port keeps the code's per-image mean (mean over the images that contain c).

### 5.2 Prototype similarity and CE (Eqs. 16, 19)

| Paper | Code (`compute_prototype_loss`) |
|---|---|
| sim_a = cos(F^d_a2, p^c_b1): perturbed features of A against B's prototypes. L^a_ce = L_ce(sim_a, ŷ^p_b1) ⊙ Mask_a. Normalisation not stated. | `pro_cos1[:, c] = cos(fts_aux1, prototypes2[c]) * scaler`, used directly as logits; `F.cross_entropy(pro_cos1, max_index2)`, then masked mean `Σ(mask·ce) / (Σ mask + 1e-16)`. `scaler = 1`. |

With `scaler = 1` the logits lie in [−1, 1]. For C classes the lowest reachable CE is
log(1 + (C−1)·e^−2). That is 0.34 for ACDC's 4 classes but **1.41 for our 24**, so the term never saturates
and keeps a near-constant gradient. **Flag:** `prototype_scale` 1 (code) | 10.

### 5.3 Cosine pull term (Eq. 20)

| Paper | Code |
|---|---|
| L^a_cos = (1 − sim_a) ⊙ Mask_a. Which class's similarity is meant is not stated. | `((1 − pro_cos1) * mask).mean()`: (1 − cos) to **every** class prototype, averaged over B × C × H × W (so pixels outside the mask count in the denominator, and the term scales with the mask fraction). It pulls each Ω2 feature towards all prototypes at once, which works against the CE term's separation. |

**Flag:** `pull_all_prototypes` on (code) | off. Off removes the term. A "pull to the pseudo-label's prototype
only" variant is a third option that is not implemented; see the decisions in `reports/pilot.md`.

### 5.4 Pairing and gradient flow

Network A's CPCL loss uses B's prototypes and B's pseudo-labels, with Mask_a (A unsure, B sure). Nothing is
detached and the code backpropagates `loss1 + loss2` jointly, so **A's CPCL loss also sends gradient into B**
through B's prototypes. The port keeps this.

## 6. DTCT: dynamic teacher on Ω3 (Eqs. 7–8, 21–25)

| Item | Paper | Code |
|---|---|---|
| Teacher selection (Eq. 21) | ŷ_t = ŷ_a1 if con_a1 ≥ con_b1, else ŷ_b1 (unperturbed outputs). | `torch.where(max_value1 > max_value2, soft1, soft2)`: ties go to B (paper: to A). |
| Sharpening (Eq. 22) | ŷ^sp = ŷ^{1/T} / (ŷ^{1/T} + (1−ŷ)^{1/T}), T = 0.1. | Same, **elementwise per class**. The result does not sum to 1 over classes. **Flag:** `sharpening` elementwise (code) \| softmax (p^{1/T} renormalised over classes). |
| Target gradient | Not stated. | **Not detached**: the MSE also pulls the winner's unperturbed output towards the perturbed one. **Flag:** `dtct_detach_target` off (code) \| on. |
| MSE (Eq. 24) | L_mse(ŷ_a2, ŷ^sp_t) ⊙ Mask. | `Σ mask·(soft_aux − sharpen(teacher))² / (Σ mask + 1e-16)`: summed over classes, averaged over Ω3 pixels. |
| Entropy (Eqs. 7, 25) | + H(ŷ_a1)⊙Mask + H(ŷ_a2)⊙Mask, H = −ŷ log ŷ. | `−Σ_c (p·mask) log(p·mask + 1e-6)` for both the unperturbed and perturbed softmax, then `.mean()` over **all** B·H·W pixels (not the Ω3 count). The two normalisations differ, so the entropy term shrinks with the Ω3 fraction while the MSE does not. |

## 7. Loss weighting and schedule (Eqs. 9–10)

| Paper | Code |
|---|---|
| L_a = L^a_s + λ(L^a_pc + L^a_mh); λ(t) = 0.1·exp(−5(1 − t/t_max)²). | `consistency_weight = 0.1 · sigmoid_rampup(iter // 150, 200)`, the same curve evaluated every 150 iterations, reaching 0.1 at iteration 30,000 = `max_iterations`. So the ramp spans the **whole run**. `loss = loss1 + loss2`, one backward pass, two optimizer steps. |

## 8. Optimisation and evaluation

| Item | Paper | Code |
|---|---|---|
| Optimizer | SGD, lr 0.01, momentum 0.9, wd 1e-4. | Same, **constant LR** (no decay anywhere). |
| Batch / iterations | ACDC: batch 16, 30k iterations. | 16 = 8 labelled + 8 unlabelled (`TwoStreamBatchSampler`). |
| Augmentation | – | Random rot90+flip or a random rotation, nearest-neighbour resize to 256². One view, shared by both networks. |
| Validation | – | Every 200 iterations, both networks separately, separate best checkpoints by mean Dice. |

## 9. The port in this repo

### Deliberate protocol changes (same for every method, so they are not flags)

| Item | Reference | Port | Why |
|---|---|---|---|
| Supervised loss | CE + Dice, unweighted | The repo's weighted CE (sqrt-inverse, capped, from the labelled subset) | One supervised loss in every method, so only the unlabelled part differs. |
| Batch | 8 L + 8 U | 4 L + 4 U | Shared batch protocol (SL 4, MT 4+4, ALHVR 4+4). |
| Backbone | 2D U-Net (16–256 ch) with encoder dropout | The repo's U-Net++ (SA off, 32–512 ch) | Same backbone in every method. |
| Optimizer / LR | SGD 0.01, constant | The repo's Adam 1e-3, 200-step warmup + cosine, one optimizer per network | Same optimizer in every method. |
| Iterations, λ ramp | 30k; ramp over 30k | 20k; λ ramp over `total_steps` (continuous, no 150-step quantisation) | The ramp spans the whole run, as in the code. |
| Augmentation | rot/flip, one view | The repo's supervised augmentation (flips, rot90, ±5°, photometric), one view shared by both networks, on labelled and unlabelled images | Same augmentation family as the other methods. |
| Prototype feature | 1/8-resolution first-decoder-stage feature (64 ch) | U-Net++ node X[3][1] (first decoder node at 1/8 resolution, 256 ch), upsampled to full resolution | The closest U-Net++ equivalent. `feature_layer: penultimate` (X[0][4], 32 ch, full resolution) is the paper's description. |
| Init | Two networks from one RNG stream | Network B built after reseeding with `seed + 1` | Different init seeds, explicitly. |
| Model selection | Best checkpoint per network | Network 1 drives validation, best checkpoint and test; the 2-network ensemble (mean softmax) is logged as secondary | Requested. |
| β | 0.8 (ACDC) | 0.8 | Reference value for the closest dataset setting; not tuned. |

### Flags (`configs/alhvr.yaml`, defaults = reference code)

| Flag | Default (code) | Alternative |
|---|---|---|
| `alhvr.cpcl.enabled` | true | false: CPCL terms are exactly 0 |
| `alhvr.dtct.enabled` | true | false: DTCT terms are exactly 0 |
| `alhvr.sharpening` | `elementwise` | `softmax` |
| `alhvr.prototype_scale` | 1 | 10 |
| `alhvr.pull_all_prototypes` | true | false |
| `alhvr.dtct_detach_target` | false | true |
| `alhvr.feature_layer` | `deep` (X[3][1]) | `penultimate` (X[0][4]) |

### Not optional (deviation from the code)

* Classes with no pixels in the batch (no pseudo-label pixel of that class in the network whose prototypes
  are used) are **skipped** in the prototype loss. They are removed from the CE softmax and from the cosine
  pull average, instead of entering as zero prototypes. The CE target class always has pixels, because it
  is the same network's pseudo-label.
* No NaN: every masked mean has a +eps denominator, an empty mask gives exactly 0, all losses are computed in
  float32, and a non-finite loss aborts the run.
