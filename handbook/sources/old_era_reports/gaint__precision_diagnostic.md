# Precision diagnostic (BenchmarkEL, final-step weights)

Mon 2026-10-05 night, gaint. No training. `scripts/precision_diagnostic.py` generates everything below the GENERATED marker. That
includes every table, `reports/diagnostics/precision_diagnostic.json` (all numbers) and `reports/diagnostics/precision_curves.csv`
(every run's full sweep curves). The section above the marker was written by hand from those numbers.

## What was run

* **Runs:** the 14 finished BenchmarkEL runs on gaint that have a final checkpoint (`checkpoints/latest.pth`, step 20,000):
  * SL-20 s0–s2, SL-100 s0, SA-SL-20 s0, SA-SL-100 s0;
  * MT-20 s0–s2, SA-MT-20 s0 (EMA teacher);
  * ALHVR-20 s0–s1 (network A);
  * Pratt-A / Pratt-C (100 %).

  cv02 runs have no checkpoints here, and the pilot runs have no final checkpoint. All runs, including SA and Pratt, are kept, so
  n = 1 for several arms.
* **Forward pass:** one pass over val + test (54 + 50 images), bf16 autocast on the GPU, the trainer's test path. Every rule below
  works on the same logits.
* **Checks** (first generated table):
  * The plain-argmax test confusion matrix is pixel-identical to `metrics.json → test_final` in 9 runs. Three runs differ by
    1–7 px. `alhvr_20pct_s0` has no stored matrix; against its CPU fp32 re-score it differs by 8,448 px, with the same
    `defect_miou` to 4 decimals.
  * Against the CPU fp32 val+test re-scores of the consolidated table, 7k–41k px of 27.3M differ (bf16 vs fp32). The resulting
    `defect_miou` differs by ≤ 0.001, except Pratt-A: 0.3239 here vs 0.3284.
  * The bias rule at b = 0 reproduces the argmax exactly (0 px). The six zero-weight classes are never predicted at any α (0 px), so
    the choice to give them no offset has no effect.
* **Relaxed precision:** a predicted crack pixel counts as correct if a ground-truth crack pixel lies within Euclidean distance 2. This
  is the disk of the existing relaxed recall.
* **Distance shares in (b):** the share of false X pixels lying within 2 / 5 px of a true crack, a true gridline and a true material
  pixel. This answers both readings of "same for gridline and material":
  * the same analysis for false gridline and false material pixels;
  * the proximity of false crack pixels to true gridline and true material.
* **Sweeps (c):**
  * The pick is the per-run maximum of **val** `defect_miou`. Ties go to the smallest |value|. The only tie is Pratt-A's α curve, which is flat because all its weights are 1.
  * **Test** is reported at that pick.
  * val + test at the pick is shown, but it contains the 54 images used to pick.
  * Val `defect_miou` is much lower than test in every run (0.17–0.27 vs 0.31–0.38 at argmax).

## Findings (numbers only; n = 3 / 3 / 2 for SL-20 / MT-20 / ALHVR-20, n = 1 elsewhere, gaint only)

**a. Crack is over-predicted by every class-weighted run.**
* On test, the 12 weighted U-Net++ runs predict 139k–228k crack px against 70.6k ground-truth px. Crack precision is 0.22–0.35;
  recall is 0.67–0.73.
  * SL-20: P 0.278 ± 0.049, R 0.726 ± 0.008.
  * MT-20: P 0.306 ± 0.006, R 0.729 ± 0.001.
  * ALHVR-20: P 0.344 ± 0.005, R 0.691 ± 0.009.
* Relaxed precision (2 px) is 0.49–0.75 (SL-20 0.611 ± 0.107, MT-20 0.681 ± 0.016, ALHVR-20 0.739 ± 0.012). So 25–51 % of
  predicted crack pixels are more than 2 px from any true crack.
* The unweighted Pratt-A run is the opposite case: P 0.631, R 0.298, 33k px. Pratt-C (crack weight 20) has P 0.253, R 0.847.
* Inactive precision (0.64–0.70) exceeds inactive recall (0.49–0.63) in all ten 20 % runs. In the four 100 % runs it is the other
  way round (SL-100 0.52 vs 0.62, SA-SL-100 0.51 vs 0.60, Pratt-C 0.55 vs 0.57, Pratt-A 0.58 vs 0.61).
* `sl_20pct_s0`, the low SL seed (test 0.306), has:
  * the most predicted crack pixels (228k);
  * the lowest crack precision (0.222);
  * the lowest relaxed precision (0.488).

**b. Where false crack pixels lie** (test; val + test is similar):
* By ground-truth class: 81–89 % background, 5–12 % inactive, 1–4 % gridline, 0.5–3 % ribbons.
* In the 13 weighted runs, 34–61 % lie within 2 px of a true crack and 51–86 % within 5 px. Pratt-A's few false crack pixels
  (12k) lie 85 % within 2 px.
  * Within 2 px: SL-20 0.34 / 0.51 / 0.54 (s0 / s1 / s2), MT-20 0.52–0.56, ALHVR-20 0.59–0.61.
  * Within 2 px of a true gridline: 2–7 %. Of true material: ≤ 0.5 %.
* So in every weighted run except `sl_20pct_s0` (0.34) and Pratt-C (0.44), half or more of the false crack pixels sit within
  2 px of a true crack, and 14–26 % lie more than 5 px from one. `sl_20pct_s0` has 49 % more than 5 px away: compared with the
  other runs, its excess is mostly crack predicted away from any crack.
* False gridline pixels: 97–98 % on background (Pratt-A 93 %), 30–37 % within 2 px of a true gridline (Pratt-A 54 %), 1–2 %
  within 2 px of a true crack (Pratt-A 5 %).
* False material pixels: 92–97 % on background (Pratt-A 86 %); 5–7 % within 2 px of true material (Pratt-A 11 %), ≤ 2 % within
  2 px of a true crack.
