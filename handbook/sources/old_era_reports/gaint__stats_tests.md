Caveats (they qualify every p above):
* **Not fully independent:** seeds run on both machines (SL-20 [0, 1, 2], SL-100 [0], SA-SL-20 [0], MT-20 [0, 1, 2], ALHVR-20 [1]) share the initialisation and the data / augmentation stream; the pooled tests treat them as independent runs.
* **76 tests, no multiple-comparison correction.** Test and val+test share the 50 test images, and mAP and mIoU the same pixels, so they are not independent either.
* Small samples (n = 1–8 per arm). The exact Mann–Whitney p has a floor: e.g. 3 vs 8 runs cannot go below 0.012, 3 vs 6 not below 0.024, 3 vs 3 not below 0.1,
  and one run against 8 not below 0.22. Welch t and Hedges g need two runs per arm.
* The batch-8 arms ran on gaint only, against references pooled over gaint + cv02; the 'Δ within gaint' column compares like with like.
  SL-10-b8 has no batch-4 SL-10 counterpart: no 10 % run exists before 2026-10-05. SL-5-b8 / SL-2-b8 use the split-seed-0 5 % / 2 %
  subsets (23 / 9 images, nested in the 10 %); their class weights differ from SL-10's (split_class_pixel_counts.md).
* All 20 % arms use one labelled subset (seed 0); the tests are about training-seed variation only, not about the choice of labelled images.
