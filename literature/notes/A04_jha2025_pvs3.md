# Jha, Rawat, Vyas 2025: PV-S3, Advancing automatic PV defect detection using semi-supervised semantic segmentation of EL images
- EAAI 160 (2025) 111790; arXiv 2404.13693 (v1 Apr 2024 to v4 Jul 2025). https://arxiv.org/abs/2404.13693
- Read: full text (local PDF) + released code (on cv02) + our reproduction (handoff §6.10).
- Method: Mean Teacher on DeepLabv3+ with a "Semi Cross-Entropy" (SemiCE) consistency loss for class imbalance. Claims SSL at 20% labels beats supervised at 100%.
- Metric: dataset-level IoU over the 4 defect classes. Background is not a class.
- Key numbers (paper): SSL-20 67.0 vs SL-20 8.76 (pvs3 convention). The released code reproduces 0.828 under the pvs3 convention but **0.050 standard** (handoff §6.10).
- Weaknesses (empirical; read: full + code). Every item is measured by us [ours] unless marked:
  - The released loss has `ignore_index=0`, so the model never predicts background. The headline exists only when pixels whose ground truth is background are dropped.
  - The released split lists put 1,769 of the 2,289 public test images into training lists and 437 into val (leakage).
  - The supervised baseline is under-trained: 30 epochs, and §4.2 says it "is not able to learn". [author-acknowledged]
  - Table 6 copies Pratt's per-image-median numbers and compares them with background-free dataset-level IoU (conventions mismatched).
  - The printed SemiCE uses Y_L for unlabelled images (notation error or ground-truth use). [reader-inferred]
- Relevance: a negative exemplar for evaluation. Our "SemiCE" port also deviates from their released code (per-class BCE on raw logits; see analysis/alhvr_audit.md).
