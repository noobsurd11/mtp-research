## 2. Readouts (in order)

### R1. A3 module-level IR screen (T26 core; no registration needed)
- **IR frame eligibility:** frames at irradiance ≥ 600 W/m² (IEC TS 62446-3 practice and the A3 paper's threshold, R) at every altitude. If irradiance is not recoverable from names or metadata, all frames are used and this is stated.
- **Module IR anomaly score (primary, frozen):** S_IR = p99 − median of the temperature array inside the module area (module area = the whole 363 × 605 array, which is module-rectified, R: README; if borders show non-module pixels, a 3% inset is applied on every side and logged). Per module, S_IR = median over eligible frames.
- **Secondary score:** cell-level ΔT_max = max over cells of the cell median minus the median of the cell medians, on a uniform grid of the detected layout (rows × cols from §1). Reported beside S_IR.
- **Readout R1a:** table per defect class: n modules, median S_IR (IQR), median ΔT_max.
- **Readout R1b:** AUROC of S_IR for each defect class vs reference modules, if a healthy / reference folder exists; otherwise one-vs-rest against all other non-soiling modules (stated which). Expected class sizes (R: DTU slides via check): cracks 8, interconnection 8, PID 6, diode 7, glass 2, soiling 6 + 6. Classes with n < 3 (glass) are reported descriptively, without AUROC. A module-bootstrap 95% CI is given for the rest (2,000 resamples).
- **Half-cut note:** the diode, glass and soiling groups include bifacial PERC 540 W half-cut modules (R: slides). Their EL is logged as the only public half-cut EL with paired IR found so far; no readout depends on it.
- **Expectation (S, from the paper):** AUROC ≥ 0.8 for interconnect disconnection and shorted bypass diode; about 0.5 for cell cracks, PID and glass cracks. No kill on R1: it is a descriptive screening table by defect mode, the deliverable for the part-3 chapter either way (top3: "a T26 kill is still a reportable result").
- **Sensitivity (reported, not a verdict):** S_IR by altitude (8 / 10 / 14 / 20 m) and by irradiance bin.

### R2. A3 screening recall vs EL (T26 with the EL-only proxy; E-PF version held)
- **EL proxy per module (frozen):** EL dark-area fraction = share of module-interior pixels (EL module quad, 3% inset) below 0.5 × the module median, after a morphological opening with a disk of radius 2% of the median cell side (removes busbars, fingers and thin cracks; keeps areas). This follows `pick3` §3.3 at module scale. Needs only the EL module outline, not IR registration.
- **Readout:** rank modules by S_IR; share of the total EL dark area held by the top 10 / 20 / 30% of modules; and the same for a crack-length proxy only if a frozen ridge filter is added by amendment (not now).
- **Kill / success (top3 / ideas T26):** success if the top 20% hold ≥ 60% of the EL dark area; kill if ≤ 20%. Labelled "EL-proxy"; the E-PF version replaces the proxy when Om allows.

### R3. G0 on A2, then A1 (needs cell registration)
- **Registration caveat:** cellreg.py's self-test shows IR outer-edge error of 6.6-9.0% of a cell side while inner residuals pass (R: check §14). Edge cells (the outer ring) are reported separately. The primary G0 verdict uses all cells that pass QA; the inner-cell verdict is reported beside it; if the two verdicts differ, G0 is reported as "inconclusive (edge-sensitive)".
- **Registration:** `pick3`'s shared `scripts/cellreg.py` (module quad → canonical grid → refined grid homography; QA residual as % of cell side). Modules with residual > 5% of a cell side are excluded and counted (pick3 T37 rule). I do not write a second tool; if `cellreg.py` is late, R3 waits and R1 / R2 go first.
- **Per-cell features (same definitions as `pick3` §3.2-3.3):** ΔT = median T over the inner 80% of the cell minus the module median of cell medians (°C); EL dark-area fraction (inner 90%, < 0.5 × module median cell-interior intensity, after the opening); candidate inactive cell = dark fraction ≥ 5%.
- **Readouts:** Spearman ρ(ΔT, dark fraction) over all registered cells (ΔT is already module-centred); AUROC of −ΔT for candidate inactive cells (predicted sign: cooler under forward bias, S; ideas §0); the same AUROC for +ΔT is reported, so an opposite-sign signal is visible. A2 and A1 are reported separately and pooled. n modules / cells / positives stated.
- **Go / kill (ideas §1.1, top3):** go if AUROC ≥ 0.8 with the predicted sign. Kill for the fusion / weak-label families only if |ρ| < 0.3 and AUROC < 0.7 in **both** conditions: dark forward-bias IR (A1 / A2, R3) **and** sunlit IR (A3, R3b). A dark-IR null alone moves those families to illuminated IR (JRC 2017 calibration, R via check), it does not kill them. A strong opposite-sign result (AUROC of −ΔT ≤ 0.2) is reported as "signal, opposite sign", not as a kill.
- **Positives check:** if fewer than 5 candidate inactive cells exist in a set, its AUROC is not computed and only ρ is reported (A1 is a resistive-loss set; Colvin 2023, R).
- **R3b (sunlit, A3):** the same ΔT / dark-fraction readout on A3, with EL registered to the 363 × 605 IR array by the module-quad homography (IR is already rectified). Frames ≥ 600 W/m², lowest altitude first (best resolution, S).

### R4. T27 and T39 (held: need E-PF)
- **T27:** AUROC of an E-PF risk score for IR-hot cells (kill if < 0.7). **T39:** share of E-PF crack components in thermally anomalous cells (kill if < 5%). Hot cell / anomalous cell = |ΔT| ≥ 2 σ_IR (σ_IR = 1.4826 × MAD of ΔT over the set), the same as `pick3` T12.
- **Prepared now (no inference):** per registered cell, a 512 × 512 grayscale EL crop with BenchmarkEL's geometry: a module crop with one central cell plus fragments of its neighbours (E: `handbook/02` §4, l.84), not a tight canonical-cell crop. The crop scale is set so the central cell's side matches BenchmarkEL's typical cell side in px (measured from our train images' geometry notes in the handbook, not from test / E1). Format and preprocessing checked against `handbook/14` and `handbook/02` before writing. A manifest with md5s. No model is loaded.
- **CPU-only pre-check now (proxy, not the verdict):** the T39 share with "EL crack proxy" is NOT computed; I will not invent a crack proxy for T39 without an amendment.

## Amendment 1 (2026-11-04, after format discovery on A2; before any G0 number is computed)
Facts found at discovery (E: `pick1/out/discovery/`): A2 modules are 72-cell (6 × 12, pseudo-square mono cells); A2 IR `.txt` is a 240 × 320 tab-separated matrix in °C (about 14-15 IR px per cell side); the NEF preview is 4928 × 3264 RGB 8-bit (both readers agree). The EL background is crushed in the preview, so no rack, cable or frame cue is visible in EL.
**Problem:** a uniform 6 × 12 (or 4 × 9) grid is symmetric under 180° rotation and under horizontal / vertical mirroring, so grid registration alone cannot tell which IR cell is which EL cell.
**Rule (frozen now):**
- Primary orientation = identity (no flip, no rotation) between the EL and IR images as stored. Reason (S): both frames are of the module front, landscape, taken in the same room minutes apart (A2: EL 18:41:34, IR 18:43:24 for 409001724, R: file names); neither camera type mirrors, and an upside-down tripod camera is unlikely. Choosing the orientation from the EL-IR agreement itself would be circular for G0, so it is not done for the primary result.
- If the dataset ships an already aligned IR crop (A1 `_cropped` files), the primary orientation is the one that maps the crop onto the EL module without flip; this is checked on the crop geometry only (outline and grid), not on intensities.
- Robustness (reported, not the verdict): G0's AUROC and ρ under all 4 orientations (identity, flip-H, flip-V, rot-180), and the "best of 4" value with a null from 1,000 within-module cell permutations that also takes the best of 4. If a non-identity orientation beats identity by > 0.15 AUROC with permutation p < 0.01, G0 is reported as "orientation unresolved" and the orientation question goes to the dataset authors (notes.md §7), not resolved by us.

## Amendment 6 (2026-11-04, after A3 format discovery; before any R1 / R2 / R3b number)

Rules (frozen now):
1. **R1 module area = the whole IR array with a 3% inset on every side** (removes the frame rim). Otsu is not used. 2. **R2 EL dark-area proxy:** computed inside the EL module outline (EL has a dark background, so Otsu works there), as frozen. 3. **R3b (sunlit cell-level G0):** classes with full-module EL only: cracks, interconnects, PID, glass (24 modules). Diode (EL partial, outline not the module) and soiling (no EL) are excluded. IR frame per module: the 8 m frame at the highest available irradiance bin (abv800); robustness: the 10 m frame. Registration with frozen cellreg 7d9a9fe0: IR quad = the full array (`--quad-ir full`), IR array rotated 90° to landscape before registration, grid detected (60-cell `6x10`, half-cut `6x24`), v2 QA (residual, pre-stated visual criteria, numeric edge check, check co-sign before any number).
4. **R3b orientation:** after the 90° turn, the four cellreg orientations (id, fliph, flipv, rot180) cover all landscape mappings; no non-outcome cue fixes which one is right (no jbox or frame cue in EL). So R3b is reported for all four, plus the best of 4 against a within-module permutation null that also takes the best of 4 (1,000, seed 20261104). Predicted sign for sunlit IR: EL-dark (inactive / disconnected) cells read **warmer** (ideas §0 physics table, S). Verdict on the best of 4: go only if best-of-4 AUROC(warmer) ≥ 0.8 **and** permutation p < 0.01; AUROC(cooler) is reported beside it; otherwise descriptive. Row/col-centred secondary as in Amendment 4. pick 3b's stratified readout uses these cells.
